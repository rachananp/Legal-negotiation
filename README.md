Legal Negotiation RL Environment

An AI agent is placed inside a real-world legal dispute and must negotiate a fair settlement between two parties. Built for the Scaler × Meta PyTorch OpenEnv Hackathon 2026.
The agent receives a case scenario — wrongful termination, security deposit disputes, contractor payment conflicts, medical negligence — and must make strategic moves: counter-offers, legal arguments, accept, or reject. The environment scores each move based on whether the settlement falls within the legally fair range, how efficiently resolution is reached, and whether legal constraints are respected.
Built with OpenEnv · FastAPI · Hugging Face Spaces
